# Тест-кейс: Проверка загрузки главной страницы GitHub

## Общая информация

| Параметр | Значение |
|---|---|
| **ID тест-кейса** | 01 |
| **Название** | Проверка загрузки главной страницы GitHub |
| **Модуль / Функциональность** | Главная страница (Home page) |
| **Тип тестирования** | Функциональное, Smoke |
| **Приоритет** | High |
| **Серьёзность** | Critical |
| **Способ выполнения** | Ручное |
| **Связанный автотест** | `главная страница GitHub загружается с корректным title и контентом` |

## Цель тест-кейса

Убедиться, что главная страница GitHub доступна и корректно загружается: открывается по прямому URL, отображает контент и имеет корректный заголовок вкладки браузера.

## Предусловия

1. Есть устройство (ПК/ноутбук) с установленным современным браузером (Chrome / Firefox / Edge / Safari актуальной версии).
2. Есть стабильное подключение к сети Интернет.
3. Пользователь не авторизован на GitHub (используется приватное окно / чистый профиль браузера).
4. Кэш браузера очищен (для чистоты проверки загрузки).

## Тестовые данные

| Данные | Значение |
|---|---|
| URL | `https://github.com/` |
| Ожидаемый title вкладки | Содержит слово «GitHub» (регистр не важен) |

## Шаги выполнения

| № | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Открыть браузер в режиме инкогнито (приватном окне) | Браузер открыт, история и кэш не используются |
| 2 | В адресной строке ввести `https://github.com/` и нажать Enter | Начинается загрузка страницы; в адресной строке отображается `https://github.com/` |
| 3 | Дождаться полной загрузки страницы | Страница загружена полностью, индикатор загрузки вкладки остановился, нет ошибок вида «Не удаётся получить доступ к сайту» / «502/503/504» |
| 4 | Проверить, что на странице отображается контент (страница не пустая, не белый экран, не страница ошибки) | Контент главной страницы виден и отрисован, отсутствуют сообщения об ошибках |
| 5 | Проверить заголовок вкладки браузера (title) | Заголовок вкладки содержит «GitHub» (регистр не важен) |
| 6 | (Дополнительно) Проверить, что в адресной строке остался `https://github.com/` (нет неожиданного редиректа) | URL соответствует главной странице, редиректов на сторонние домены/страницу логина нет |

## Ожидаемый общий результат

Все проверки пройдены — тест-кейс считается **PASSED**. Главная страница GitHub успешно загружается, отображает контент и имеет корректный title, содержащий «GitHub».

## Постусловия

- Закрыть приватное окно браузера.
- Очистить кэш (при необходимости).
- Дополнительных изменений в данных не требуется (проверка read-only).

## Возможные причины падения (failure)

| Проверка | Возможная причина |
|---|---|
| Загрузка страницы | Нет доступа к сети, GitHub недоступен, ошибка DNS, блокировка провайдером/файрволом |
| Контент страницы | Ошибка на стороне сервера (5xx), белый экран из-за ошибки JS/CSS, страница обслуживания |
| Title | Изменён заголовок на странице, редирект на другую локаль/страницу |
| URL | Неожиданный редирект (гео-редирект, A/B-редирект, страница обслуживания) |

## Замечания и рекомендации

1. **Кросс-браузерность**: рекомендуется прогнать кейс минимум в Chrome, Firefox и Safari/Edge.
2. **Сеть**: для чистоты результата проверять при стабильном соединении; при медленной сети — дождаться полной загрузки.
3. **Согласованность с автотестом**: ручной кейс покрывает те же ключевые проверки (загрузка страницы, title, наличие контента), что и автотест, и может использоваться как эталон для приёмки автоматизации.
