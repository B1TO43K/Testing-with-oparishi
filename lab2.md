# Тест-кейс: Проверка открытия меню "Products" в шапке сайта GitHub

## Общая информация

| Параметр | Значение |
|---|---|
| **ID тест-кейса** | 04 |
| **Название** | Проверка открытия меню "Products" в шапке сайта GitHub |
| **Модуль / Функциональность** | Главная страница (Home page) — навигационное меню в шапке (Header navigation) |
| **Тип тестирования** | Функциональное, UI |
| **Приоритет** | Medium |
| **Серьёзность** | Major |
| **Способ выполнения** | Ручное (связанный автотест: Playwright) |
| **Связанный автотест** | `Гость может открыть меню "Products" в шапке сайта` |

## Цель тест-кейса

Убедиться, что неавторизованный пользователь (гость) может открыть выпадающее меню **«Products»** в шапке главной страницы GitHub, увидеть в нём пункт **«Actions»** и перейти по нему на страницу `https://github.com/features/actions`.

## Предусловия

1. Есть устройство (ПК/ноутбук) с установленным современным браузером (Chrome / Firefox / Edge / Safari актуальной версии).
2. Есть стабильное подключение к сети Интернет.
3. Пользователь не авторизован на GitHub (используется приватное окно / чистый профиль браузера).
4. Кэш браузера очищен (для чистоты проверки загрузки).
5. Главная страница GitHub успешно загружается (см. тест-кейс ID 01).

## Тестовые данные

| Данные | Значение |
|---|---|
| URL | `https://github.com/` |
| Название кнопки меню | `Products` |
| Название пункта меню | `Actions` |
| Ожидаемый URL после перехода | `https://github.com/features/actions` (соответствует regex `.*\/features\/actions`) |
| Таймаут появления кнопки «Products» | 15 000 мс |
| Таймаут появления ссылки «Actions» | 5 000 мс |

## Шаги выполнения

| № | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Открыть браузер в режиме инкогнито (приватном окне) | Браузер открыт, история и кэш не используются |
| 2 | В адресной строке ввести `https://github.com/` и нажать Enter | Начинается загрузка страницы; в адресной строке отображается `https://github.com/` |
| 3 | Дождаться загрузки страницы (событие `DOMContentLoaded`) | Страница загружена, шапка сайта отображается, ошибок доступа нет |
| 4 | Найти в верхнем меню (шапке) кнопку **«Products»** | Кнопка «Products» видна и доступна для взаимодействия (в пределах 15 000 мс) |
| 5 | Кликнуть по кнопке **«Products»** | Открывается выпадающее меню с пунктами навигации |
| 6 | Проверить наличие пункта **«Actions»** в открывшемся меню | Ссылка «Actions» видна в меню (в пределах 5 000 мс) |
| 7 | Кликнуть по ссылке **«Actions»** | Выполняется переход на страницу с описанием функции Actions |
| 8 | Проверить URL текущей страницы | URL соответствует `https://github.com/features/actions` (regex `.*\/features\/actions`) |

## Ожидаемый общий результат

Все проверки пройдены — тест-кейс считается **PASSED**. Гость может открыть меню «Products» в шапке сайта, увидеть пункт «Actions» и успешно перейти на страницу `https://github.com/features/actions`.

## Постусловия

- Закрыть приватное окно браузера.
- Очистить кэш (при необходимости).
- Дополнительных изменений в данных не требуется (проверка read-only).

## Возможные причины падения (failure)

| Проверка | Возможная причина |
|---|---|
| Загрузка страницы | Нет доступа к сети, GitHub недоступен, ошибка DNS, блокировка провайдером/файрволом |
| Кнопка «Products» | Изменена структура шапки сайта, кнопка скрыта для гостя, изменился текст/локализация, A/B-эксперимент |
| Пункт «Actions» в меню | Изменён состав меню, переименован пункт, меню не раскрылось (ошибка JS) |
| Переход по ссылке | Неверный `href`, редирект на другую страницу, страница обслуживания (5xx) |
| URL после перехода | Изменился путь `/features/actions`, добавлен редирект или локаль в URL |
