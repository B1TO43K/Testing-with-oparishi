# Тест-кейс: Проверка футера и ссылок на политики на главной странице GitHub

## Общая информация

| Параметр | Значение |
| :--- | :--- |
| **ID тест-кейса** | 03 |
| **Название** | Проверка отображения футера и ссылок на политики и продукты |
| **Модуль / Функциональность** | Главная страница (Home page) / Подвал (Footer) |
| **Тип тестирования** | Функциональное, Smoke, Regression |
| **Приоритет** | Medium |
| **Серьёзность** | Normal |
| **Способ выполнения** | Автоматизированное / Ручное |
| **Связанный автотест** | `футер содержит ссылки на политики и продукты` |

---

## Цель тест-кейса

Убедиться, что на главной странице GitHub в нижней части отображается элемент подвала (`footer`), содержащий видимые и доступные ссылки на правовые документы сервиса (`Privacy`, `Terms`), готовые для перехода пользователей.

---

## Предусловия

1. Есть устройство (ПК/ноутбук) с установленным современным браузером (Chrome / Firefox / Edge / Safari актуальной версии).
2. Есть стабильное подключение к сети Интернет.
3. Пользователь не авторизован на GitHub (используется приватное окно / чистый профиль браузера).
4. Кэш браузера очищен (для чистоты проверки загрузки ресурсов и разметки).

---

## Тестовые данные

| Данные | Значение |
| :--- | :--- |
| **URL** | `https://github.com/` |
| **Ожидаемый контейнер** | `footer` (последний на странице) |
| **Ожидаемые ссылки** | Ссылки с текстом `Privacy` и `Terms` (регистр не важен) |
| **Ожидаемый атрибут** | Атрибут `href` у ссылки Privacy не пустой |

---

## Шаги выполнения

| № | Шаг | Ожидаемый результат |
| :-: | :--- | :--- |
| **1** | Открыть браузер в режиме инкогнито (приватном окне) | Браузер открыт, история и кэш не используются |
| **2** | В адресной строке ввести `https://github.com/` и нажать Enter | Начинается загрузка страницы; в адресной строке отображается `https://github.com/` |
| **3** | Дождаться первичной загрузки страницы (событие `domcontentloaded`) | Страница загружена полностью, DOM-дерево готово к взаимодействию, нет ошибок вида «Не удаётся получить доступ к сайту» / «502/503/504» |
| **4** | Прокрутить страницу вниз к элементу подвала (`footer`) и проверить его видимость | Элемент `footer` найден на странице, прокручен в зону видимости (viewport) и отображается пользователю |
| **5** | Найти в подвале ссылку на политику конфиденциальности (`Privacy`) и проверить её видимость | Ссылка с текстом «Privacy» найдена в контейнере `footer` и видна на экране |
| **6** | Найти в подвале ссылку на условия использования (`Terms`) и проверить её видимость | Ссылка с текстом «Terms» найдена в контейнере `footer` и видна на экране |
| **7** | Проверить наличие и заполненность атрибута `href` у ссылки Privacy | Атрибут `href` существует, не равен `null` / пустой строке и содержит корректную гиперссылку |

---

## Ожидаемый общий результат

Все проверки пройдены — тест-кейс считается **PASSED**. Главная страница GitHub успешно загружается, подвал (`footer`) виден при скролле, ссылки на политики («Privacy» и «Terms») отображаются и содержат непустые ссылки для перехода.

---

## Постусловия

* Закрыть приватное окно браузера / завершить сессию теста.
* Очистить кэш (при необходимости).
* Дополнительных изменений в данных не требуется (проверка read-only).
