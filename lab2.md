# Тест-кейс: Поиск репозитория «playwright» возвращает результаты

## Общая информация

| Параметр | Значение |
|---|---|
| **ID тест-кейса** | 07 |
| **Название** | Поиск репозитория «playwright» возвращает результаты |
| **Модуль / Функциональность** | Поиск по репозиториям |
| **Тип тестирования** | Функциональное, E2E |
| **Приоритет** | High |
| **Серьёзность** | Critical |
| **Способ выполнения** | Автоматизированный (Playwright) |
| **Связанный автотест** | `поиск репозитория "playwright" возвращает результаты` |

## Цель тест-кейса

Убедиться, что поиск по репозиториям по запросу «playwright» возвращает релевантные результаты, среди которых присутствует хотя бы один репозиторий, и что по клику на результат происходит переход на страницу репозитория с корректным URL.

## Предусловия

1. Есть устройство (ноутбук) с установленным браузером (Playwright-совместимый: Chromium / Firefox / WebKit).
2. Есть стабильное подключение к сети Интернет.
3. Пользователь не авторизован на GitHub.
4. Кэш браузера очищен (используется чистый контекст Playwright).
5. Настроен `baseURL` = `https://github.com`.

## Тестовые данные

| Данные | Значение |
|---|---|
| URL поиска | `/search?q=playwright&type=repositories` |
| Поисковый запрос | `playwright` |
| Тип поиска | `repositories` |
| Ожидаемое содержимое страницы | Текст, содержащий «playwright» (без учёта регистра) |
| Ожидаемые ссылки на репозитории | Ссылки вида `a[href*="/microsoft/playwright"]` или `a[href*="/playwright"]` |

## Шаги выполнения

| № | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Открыть страницу поиска `https://github.com/search?q=playwright&type=repositories` с ожиданием `domcontentloaded` | Страница поиска загружена, DOM построен; в адресной строке отображается URL поиска |
| 2 | Дождаться отображения тела страницы и проверить, что оно содержит текст «playwright» (без учёта регистра) | В теле страницы присутствует текст, соответствующий `/playwright/i`; сообщений об ошибках нет |
| 3 | Найти ссылки на репозитории по селектору `a[href*="/microsoft/playwright"], a[href*="/playwright"]` и проверить, что первая из них видима | На странице есть хотя бы один результат поиска — ссылка на репозиторий; первая ссылка видима пользователю |
| 4 | Кликнуть по первой найденной ссылке на репозиторий | Происходит переход на страницу выбранного репозитория |
| 5 | Проверить URL текущей страницы на соответствие шаблону `/\/[\w-]+\/[\w-]+/` | URL соответствует формату страницы репозитория `/<owner>/<repo>`; переход выполнен успешно |

## Ожидаемый общий результат

Все проверки пройдены — тест-кейс считается **Пройденным**. Поиск по запросу «playwright» среди репозиториев возвращает страницу с релевантным содержимым, на ней присутствует хотя бы одна видимая ссылка на репозиторий, и по клику на неё происходит переход на страницу репозитория с корректным URL вида `/<owner>/<repo>`.
